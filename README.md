🛒 E-commerce SQL Analytics Project
📌 Project Overview

This project focuses on analyzing an E-commerce dataset using SQL to answer business-related queries ranging from basic to advanced difficulty.

The queries help uncover insights such as:
-Customer distribution by city and state
-Monthly order patterns
-Product category contributions to revenue
-Revenue generated by sellers
-Year-over-year growth trends
-Customer purchase behavior

The goal is to demonstrate SQL skills by solving real-world business questions and showcase capabilities in data analysis, trend identification, and advanced SQL window functions.

🗂 Dataset

The project uses a sample E-commerce dataset containing:

customers → customer demographics (city, state)
orders → order details and timestamps
order_items → product-level details for each order
products → product categories and attributes
sellers → seller details
payments → order payment details

🛠️ Tech Stack

SQL Server / MySQL (SQL queries & execution)
Git & GitHub (version control & project showcase)

📊 Query Categories
🔹 Basic Queries

-List all unique cities where customers are located.
-Count number of orders placed in 2017.
-Find total sales per category.
-Calculate percentage of orders paid in installments.
-Count number of customers from each state.

🔹 Intermediate Queries

-Orders per month in 2018.
-Average number of products per order by customer city.
-Revenue contribution by each product category.
-Correlation between product price & purchase frequency.

Rank sellers by total revenue.

🔹 Advanced Queries

-Moving average of order values per customer.
-Cumulative monthly sales per year.
-Year-over-year growth of total sales.
-Top 3 customers by spending for each year.

📈 Key Insights from Queries

-Cities & States → Distribution of customers shows concentration in specific regions.
-Product Categories → Certain categories dominate revenue contribution.
-Installment Payments → A significant share of orders are paid via installments.
-Seasonality → Order trends highlight peaks in specific months.

Seller Analysis → Revenue is unevenly distributed across sellers.

Customer Trends → Identified top spenders and their contribution over time.
